# Uploads (staging)

Drop raw, unprocessed photos here via git push. This folder is **not**
referenced by any page — nothing here shows up on the live site
automatically.

Workflow:
1. Push photos into this folder (any filenames are fine).
2. Process them as needed (e.g. remove a watermark, crop, resize).
3. Move the finished version into `images/` (or wherever the site needs
   it) and wire it into the actual page.

Feel free to delete a file from here once it's been processed and moved.

## processed/

Finished versions of the photos in this folder — watermark removed and
upscaled 1.5x with mild sharpening, saved as web-friendly JPEGs. The
originals above are left untouched. These aren't wired into any page
yet; say the word and they can be placed (staff photos, gallery,
homepage hero, etc.).
